# 權限系統使用說明

## 📚 第一步完成：新權限系統建立

已經成功建立了新的權限配置系統，**完全不會影響現有功能**！

## 🆕 新增的檔案

### 1. `permission-config.service.ts`
- 集中管理所有功能的權限配置
- 定義了各種模組的權限要求（users, agents, orders, finance 等）
- 提供權限檢查的方法

### 2. `permission.decorator.ts`
- `@RequirePermission('users.create')` - 單一權限檢查
- `@RequireAnyPermission(['a', 'b'])` - 任一權限即可
- `@RequireAllPermissions(['a', 'b'])` - 必須全部權限

### 3. `permission.guard.ts`
- 新的權限守衛，基於配置檔進行檢查
- 提供詳細的錯誤訊息

### 4. `permission-test.controller.ts`
- 測試用控制器，示範各種用法

## 🎯 使用方式

### 舊方式 (目前仍正常運作)
```typescript
@Roles(UserRole.SUPER_ADMIN, UserRole.GLOBAL_ADMIN, UserRole.AGENT_LEVEL_1)
@Get('users')
getUsers() { ... }
```

### 新方式 (語義更清楚)
```typescript
@RequirePermission('users.view')
@Get('users') 
getUsers() { ... }
```

## 🔧 測試方式

啟動後端後，可以測試這些端點：

```bash
# 需要 users.view 權限 (SUPER_ADMIN, GLOBAL_ADMIN, AGENT_LEVEL_1, AGENT_LEVEL_2 可存取)
GET /permission-test/users

# 需要 users.create 權限 (SUPER_ADMIN, GLOBAL_ADMIN, AGENT_LEVEL_1 可存取)  
POST /permission-test/users

# 需要 agents.view 或 users.view 任一權限
GET /permission-test/dashboard

# 需要 users.view 和 agents.view 全部權限
GET /permission-test/admin-panel

# 需要 system.maintenance 權限 (只有 SUPER_ADMIN 可存取)
DELETE /permission-test/system/reset

# 無權限限制
GET /permission-test/public
```

## 📋 權限配置概覽

目前已定義的權限：

### 用戶管理
- `users.view` - 查看用戶
- `users.create` - 建立用戶  
- `users.edit` - 編輯用戶
- `users.delete` - 刪除用戶

### 代理商管理
- `agents.view` - 查看代理商
- `agents.create` - 建立代理商
- `agents.commission` - 管理佣金
- `agents.manage` - 管理代理商

### 訂單管理
- `orders.view` - 查看訂單
- `orders.manage` - 管理訂單
- `orders.create` - 建立訂單

### 財務管理
- `finance.view` - 查看財務
- `finance.withdraw` - 提領操作
- `finance.balance` - 餘額操作

### 系統管理
- `system.config` - 系統設定
- `system.maintenance` - 系統維護

## ⚡ 優點

1. **語義清楚** - `users.create` 比一串角色名稱更好理解
2. **集中管理** - 所有權限配置在一個檔案中
3. **不會遺漏** - 新增功能時，只要在配置檔新增即可
4. **向後兼容** - 舊的 `@Roles()` 系統依然正常運作
5. **易於擴展** - 將來擴展到 12 級代理商只需修改配置檔
